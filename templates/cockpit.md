# Cockpit – open topics

> **Structure mirrors your filing:** the sections below follow your folders and areas.
>
> **Pointer rule:** every reference to a work state names a path or a link – never "in the chat". A chat is not a filing place.
>
> **Leading place beats cockpit:** if a topic is maintained elsewhere (a spreadsheet, the task app, a wiki), the cockpit only points there.
>
> **One home per topic:** each topic appears once, in the section it belongs to.
>
> **State markers:** `▶` running · `⏳` waiting for someone (since when) · `⏸` paused until (date or condition) · `✅` done (moves to the archive).
>
> **Weekly review (e.g. Mondays):** check each line against three questions – is the state still right? who is it waiting for? is it still needed?
>
> Last updated: 2026-03-02, by the weekly review session
